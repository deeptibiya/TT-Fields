# Literature Database

This directory contains the structured evidence base for the TTFields project.

## Phase 1 focus

During W 1–4, prioritize literature addressing:

- TTFields biological rationale
- Mechanisms affecting mitosis and cytokinesis
- Microtubule and spindle disruption
- Cellular stress and related responses
- DNA damage and repair where supported
- Glioblastoma and relevant preclinical models
- Reproducibility and translational relevance

## Source-recording principle

Every included source should be recorded with enough information to identify the publication and trace the claim back to the original evidence.
